# CF12 local-source-type full-class replay draft

Status: private v2 draft, not root-reviewed and not run. No CLI, Java compiler, JADX, Git, Cargo, or Jarde command has been executed for this draft. It makes no product acceptance claim.

The intended runner is `prepare-local-source-types-replay-luna-v2.py`; the independent read-only checker is `verify-local-source-types-replay-luna-v2.py`. Root must provide the exact candidate CLI path and SHA-256, metadata path and SHA-256, validation execution path/SHA-256, source-base commit, JDK 8/23 homes, and pinned JADX path/SHA-256 when invoking them. The helper/product/test-SDK classpath is rebuilt from the accepted direct-harness inventory (fresh helper classes plus the exact 57 product jars and 6 official SDK jars); source bytes and no-target leakage are rechecked. There are no guessed future hashes, commits, CLI outputs, or runtime outcomes. Each result directory must be absent before collection; neither script may replace evidence.

The collector takes the accepted CF12 input/render/full-replay bundle as a read-only historical baseline. It must verify the `observation-acceptance-root-v6.json` digest and its three accepted evidence directories before reusing any input. It keeps the six JUnit methods, eight captured class instances, `check()`/`Inner`, and the original SDK/helper classpath. Switch test target classes are never copied into the helper classpath. The original and JADX runs in that bundle remain historical baseline observations; every new candidate run is separately recorded with exact argv, exit code, stdout/stderr bytes and SHA-256.

For both local-source-type anchors (`TestSwitch.test` and `TestSwitchNoDefault.test`), collect default and `all` complete class-source reports from the new frozen CLI. Recompile each complete class for both pinned Java 8 and Java 23 legs and run the complete class through the frozen `Cf12RuntimeProbe` inputs. The verifier compares the new stdout and stderr independently with that same JDK leg's original class raw; both profiles must compile and match. It also checks default/all complete source text and method source maps, and requires complete physical BCI ownership for the affected methods against the exact captured class. Source-map claims must be read from actual report JSON and cross-checked against raw `javap`; do not infer successful coverage from the CLI's summary fields.

The other three fixture families (`TestSwitchFallThrough`, both `TestSwitchLabels` profiles, and `TestSwitchWithFallThroughCase`) are controls. For every source class/profile, compare the new candidate's complete text and source maps byte-for-byte/structurally with the accepted root-v6 report for that exact class instance. Their old whole-class replay classification must remain exact: fallthrough and Labels match the original; conditional fallthrough remains a compile failure. This check records the old classification and requires the new run to preserve it; it does not claim that the conditional-fallthrough refusal is fixed.

The standalone `LocalSourceTypesBoundaries.java` / `BoundaryRunner.java` under `/private/tmp/jarde-local-source-types-boundaries-luna-v1/` are the early private draft. For replay, use the root-corrected frozen Java sources in `recover-proved-local-source-types/results/boundary-preflight-root-v1/`; the private draft remains unchanged as history. The preflight's class files are not replay inputs: compile the source afresh with Java 8 and Java 23, then run it. Decompile each fresh class with the pinned JADX, compile/run the full JADX source plus the unchanged runner, and collect new-CLI `default` and `all` reports, compilations, and executions on both JDK legs. The known char and exact-null/String positive cases must preserve full runner stdout/stderr. Record per-label output slices for the neighboring int/mixed-reference/unknown-copy/slot-reuse cases, but do not require those cases to fail or force a legacy fallback: an independent existing proof route may still preserve behavior. Read actual class bytes and bytecode before claiming slot reuse or producer/phi ownership; the source fixture does not encode SSA facts.

The independent checker must verify raw stream hashes from files, exact source/class pins, command argv/JDK bindings, exit classifications, classpath target exclusion, original-vs-candidate raw comparisons, default/all maps, the unaffected root-v6 body/map controls, and complete anchor BCI ownership. It must not trust a recorded `runtime_raw_equal_original` boolean, a CLI coverage summary, or a collector's `status` alone. It writes an acceptance observation only after every check passes and labels the result as this change's local-type evidence; it must not mark all CF12 complete.


The v2 contract fixes input provenance: each copied JADX source is keyed by its original relative path and compared byte-for-byte with the accepted original; `default` and `all` reports are held in separate profile maps; each report is tied to the exact command row and raw stdout that created it. The runtime probe contract is `... Cf12RuntimeProbe <fqcn> <caseRoot>` (the last two argv elements are the fully-qualified class name and case root). The validation freeze binds CLI path/SHA and metadata path, while the metadata separately binds the validation execution SHA; it intentionally does not require a metadata SHA inside the freeze record. The boundary preflight must match the actual `typed-local-java-boundary-preflight-root-v1` top-level key set and source-file keys.

The affected method check uses exact method name and descriptor from the real class-source JSON and exact matching `javap -p -c -s -v` method section. It also checks the rendered member owner identity against the same class byte digest/snapshot and requires every physical BCI for that exact method to appear in the report source map. Controls preserve their explicit old compile/runtime classification. Boundary output comparison checks the entire stdout and stderr of every successful candidate runtime and then compares every labeled line, including the int, mixed-reference, unknown-copy, and slot-reuse negatives. This does not require an unrelated pre-existing fallback to become compilable; a refused candidate remains a recorded refusal and must be reviewed as such rather than presented as a runtime pass.

`int-overload-replay-plan.md` is a separate planned replay for the actual original fixture in `results/int-overload-original-root-v1/`. It is not included in this collector run and has not been executed by this draft.


## Separate int-overload exact-input replay plan (not part of this run)

The only accepted starting point is `openspec/changes/recover-proved-local-source-types/results/int-overload-original-root-v1/`. Its existing source is `CharProducerIntOverload.java`, its original class SHA-256 is `18098c9d7257fabb8497107e42e86695be956dba666598ebd82daa2512722cd8` (632 bytes), and the original run is exactly `46\n`. The saved `javap -p -c -s -v` proves two distinct relevant descriptors: `render(Ljava/lang/String;)Ljava/lang/String;` calls `String.charAt(I)C` at BCI 2 and `StringBuilder.append(I)Ljava/lang/StringBuilder;` at BCI 17; the overloaded `append(C)` must never be inferred from a source-level char local. The source has a later literal assignment `value = 46`, so any candidate proof must also explain the actual reaching write/SSA definition rather than treat the char producer alone as sufficient.

A separate runner should, for `default` and `all`, collect complete class-source JSON for the exact original class bytes, save each report's stdout raw and SHA, extract and save the complete class source, compile that full source with the exact accepted Java 8 flags (`-source 8 -target 8 -g:none -proc:none -Xlint:-options`, empty `-classpath` and `-sourcepath`, no implicit source discovery), then run the recompiled `CharProducerIntOverload`. It must capture stdout/stderr/argv/SHA and compare the entire output with the original `46\n`; it must also inspect the source and the exact method descriptor in report JSON, then re-run `javap` on the frozen original and fresh candidate class to bind `append(I)` and actual local stores. The original `javac` command record pins JDK 23.0.1 and exact options; the previous class is only a read-only baseline, and the fresh run must compile into an exclusive new directory. Record both profile bodies/maps independently and require default/all equality. This planned replay has not been executed, and output equality alone is not overload proof.
