# CF12 local-source-type full-class replay draft

Status: private draft, not root-reviewed and not run. No CLI, Java compiler, JADX, Git, Cargo, or Jarde command has been executed for this draft. It makes no product acceptance claim.

The intended runner is `prepare-local-source-types-replay-luna-v1.py`; the independent read-only checker is `verify-local-source-types-replay-luna-v1.py`. Root must provide the exact candidate CLI path and SHA-256, metadata path and SHA-256, validation execution path/SHA-256, source-base commit, JDK 8/23 homes, and pinned JADX path/SHA-256 when invoking them. The helper/product/test-SDK classpath is rebuilt from the accepted direct-harness inventory (fresh helper classes plus the exact 57 product jars and 6 official SDK jars); source bytes and no-target leakage are rechecked. There are no guessed future hashes, commits, CLI outputs, or runtime outcomes. Each result directory must be absent before collection; neither script may replace evidence.

The collector takes the accepted CF12 input/render/full-replay bundle as a read-only historical baseline. It must verify the `observation-acceptance-root-v6.json` digest and its three accepted evidence directories before reusing any input. It keeps the six JUnit methods, eight captured class instances, `check()`/`Inner`, and the original SDK/helper classpath. Switch test target classes are never copied into the helper classpath. The original and JADX runs in that bundle remain historical baseline observations; every new candidate run is separately recorded with exact argv, exit code, stdout/stderr bytes and SHA-256.

For both local-source-type anchors (`TestSwitch.test` and `TestSwitchNoDefault.test`), collect default and `all` complete class-source reports from the new frozen CLI. Recompile each complete class for both pinned Java 8 and Java 23 legs and run the complete class through the frozen `Cf12RuntimeProbe` inputs. The verifier compares the new stdout and stderr independently with that same JDK leg's original class raw; both profiles must compile and match. It also checks default/all complete source text and method source maps, and requires complete physical BCI ownership for the affected methods against the exact captured class. Source-map claims must be read from actual report JSON and cross-checked against raw `javap`; do not infer successful coverage from the CLI's summary fields.

The other three fixture families (`TestSwitchFallThrough`, both `TestSwitchLabels` profiles, and `TestSwitchWithFallThroughCase`) are controls. For every source class/profile, compare the new candidate's complete text and source maps byte-for-byte/structurally with the accepted root-v6 report for that exact class instance. Their old whole-class replay classification must remain exact: fallthrough and Labels match the original; conditional fallthrough remains a compile failure. This check records the old classification and requires the new run to preserve it; it does not claim that the conditional-fallthrough refusal is fixed.

The standalone `LocalSourceTypesBoundaries.java` / `BoundaryRunner.java` under `/private/tmp/jarde-local-source-types-boundaries-luna-v1/` are the early private draft. For replay, use the root-corrected frozen Java sources in `recover-proved-local-source-types/results/boundary-preflight-root-v1/`; the private draft remains unchanged as history. The preflight's class files are not replay inputs: compile the source afresh with Java 8 and Java 23, then run it. Decompile each fresh class with the pinned JADX, compile/run the full JADX source plus the unchanged runner, and collect new-CLI `default` and `all` reports, compilations, and executions on both JDK legs. The known char and exact-null/String positive cases must preserve full runner stdout/stderr. Record per-label output slices for the neighboring int/mixed-reference/unknown-copy/slot-reuse cases, but do not require those cases to fail or force a legacy fallback: an independent existing proof route may still preserve behavior. Read actual class bytes and bytecode before claiming slot reuse or producer/phi ownership; the source fixture does not encode SSA facts.

The independent checker must verify raw stream hashes from files, exact source/class pins, command argv/JDK bindings, exit classifications, classpath target exclusion, original-vs-candidate raw comparisons, default/all maps, the unaffected root-v6 body/map controls, and complete anchor BCI ownership. It must not trust a recorded `runtime_raw_equal_original` boolean, a CLI coverage summary, or a collector's `status` alone. It writes an acceptance observation only after every check passes and labels the result as this change's local-type evidence; it must not mark all CF12 complete.
