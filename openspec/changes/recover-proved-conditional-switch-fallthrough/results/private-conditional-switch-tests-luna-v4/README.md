# CF12 conditional-switch test draft v4

`p3_conditional_switch_fallthrough.rs` is a private, uncompiled test draft for the next review. It does not change the repository and no Rust, Cargo, JDK, Git, or Jarde command was run for this draft. The v2 and v3 drafts remain untouched.

The test now follows the real-class facade path used by `crates/jarde-java/tests/proved_discarded_call_origins.rs`: it analyzes the frozen class at Java 8, takes declaration/access/parameter/debug-local facts from that same reader-backed `MethodIr`, finds the unique method ordinal by exact raw name and descriptor, binds an `ArtifactSubject` to the analysis method and environment identity, and verifies the resulting binding. It includes no caller-authored method flags or slot count. The embedded class remains the complete upstream 1563-byte target class; its BLAKE3 is pinned to `92a103230cd6cbb8ccc535ca33a838ad3c91265b1b784d5ad5a69db824b17edd`.

The region ownership assertions were checked against the current source contract. `report.rs` materializes one `RegionRecord` for each element of the recovered top-level `regions` vector. `Region::Switch::blocks()` returns its dispatch/prefix and concatenates each group's arm blocks recursively; it does not create separate child `RegionRecord`s. `SwitchBreak::blocks()` is empty, so its control origin cannot claim the join. This makes counting each observed canonical block once across top-level report records a check of the method's published ownership, while separately requiring 117 once inside the switch and 171 absent from it.

The positive assertions are tied to the accepted real-IR observation: switch BCI 7, case entries 32/117/146/149, join 171, the 11 observed block starts, and physical goto instructions at BCIs 89 and 114. It compares default/all text and maps exactly; checks all reader-inspected instructions have source from the same physical method; checks region claims give each observed block one owner, case 2 appears once, and join 171 is outside the switch span; and requires each goto origin to own exactly one complete `break;` span. It deliberately does not hardcode the whole new body, a whole-map snapshot, or the total number of `break;` tokens. The only acceptance claim this test could support is the focused recovery contract; root still needs a fresh full-class compile/runtime replay against the original and JADX outputs.

The pre-cancelled recovery test checks only the public atomic Stop contract with a fresh recovery budget. It does not assert cancellation during the conditional proof or a step cost. Root should capture an actual proof trace before adding an exact AnalysisSteps boundary test; do not add a test-only trace hook.

## Boundary-test design to carry forward

The current frozen graph establishes one positive DAG only: all 17 canonical edges are Normal and have empty clone paths; there are no canonical Return, Exception, or Call rows; no case-local physical return/throw; no cycle; no external interior predecessor; and no nested switch/loop target. The current fixture therefore cannot substantiate those negative claims. Its real ownership facts are: 117 has dispatch and case-1 incoming edges but must belong only to case 2; 171 is the shared join after every case; case-1 exits to 171 are physical gotos at 89 and 114.

For later adversarial tests, first select or freeze a real class fixture for each shape and retain its exact original bytes, reader inspection, full canonical edge multiset, edge kinds, clone paths, and incoming sets. Do not synthesize a normal-flow projection or claim an unobserved canonical graph. The intended cases are:

- Hidden canonical Exception, Call, or subroutine Return incident to the candidate proof. The fixture must show that the normal-flow projection omits the edge while the full canonical facts retain it; expected result is refusal.
- A duplicate Normal edge, differing clone path, external incoming edge to an interior node, or unproved predecessor at a case entry. The fixture's exact edge multiplicity and path identity must be recorded before asserting refusal.
- A cycle/backedge, two distinct case exits, a later/non-adjacent case target, an unknown terminal, and a terminal Return/Throw with a canonical outgoing edge. Each refusal assertion should name the raw physical instruction and complete canonical row that violates closure. A valid physical return/throw leaf needs its own fixture with a decoded terminal opcode and zero canonical outgoing rows.
- Nested switch and inner-loop cases where a path exits a parent switch. Verify the exact nearest breakable scope from a real canonical graph; the unsupported cross-scope case must refuse rather than emit an unlabelled break for the wrong switch.
- Budget/cancellation during candidate adjacency collection, bounded traversal, and incoming validation. Determine costs from real tracing; each stopped run must publish no text or source map. The current atomic-cancellation test is not a substitute for those checkpoints.

No fixture for these negative boundaries is asserted by this draft. The existing real-class diagnostic and this proposed positive test also do not establish whole-class compilation or runtime equality; those remain root-owned replay checks. v4 corrects v3's mistaken pinned digest; v3 remains unchanged.
