# Conditional switch boundary fixtures (private draft)

Not compiled or run. This directory contains complete Java 8 source for five semantic shapes and a deterministic runner. It does not assert a CFG, region tree, or Jarde recovery outcome.

`ConditionalSwitchBoundaries.java` keeps each switch and all of its members intact. The runner covers selectors `-1, 0, 1, 2`, both boolean-like integer inputs, and both nested-switch selectors. It prints one stable labeled line per invocation. `terminalCase` is wrapped by the runner so return and exception outcomes are both printed.

Expected Java-level behavior, derived from source only:

- `partialBreak`: selector 0 with flag 1 returns `A`; selector 0 with flag 0 falls through and returns `FB`; selector 1 returns `B`; default returns `D`. The `break` is inside one `if` arm but targets the outer switch.
- `innerLoopBreak`: selector 0 returns `ON` for flag 0 and `LON` for flag 1. The `break` exits only the `while`; execution then reaches the following outer case label. It must not be treated as an outer-switch exit.
- `innerSwitchBreak`: selector 0 returns `ION` or `JON`; the inner switch's `break` exits only that inner switch, and the outer switch then falls through to case 1.
- `terminalCase`: selector 0 returns `R`; selector 1 throws `IllegalArgumentException` with message `T`; selector 2 returns `C`; default returns `D`. These are source-level return/throw terminals, not claims about canonical edge kinds.
- `caughtExceptionThenFallthrough`: selector 0 with flag 0 returns `7N`; with flag 1 it catches `NumberFormatException` and returns `CN`; selector 1 returns `N`; default returns `D`. The call to `Integer.parseInt` is inside the case-local try/catch and its result or caught path continues into case 1.

For each eventual classfile, root should record exact class bytes, method descriptors, physical instructions, complete canonical edge rows including kind and clone path, and the nearest breakable owner at each break. In particular, verify which physical source exits the outer switch in `partialBreak`; that the `innerLoopBreak` edge reaches the loop continuation while remaining in the outer switch; that inner-switch breaks target the inner switch; that return/throw cases are actual terminal operations with the observed canonical outgoing-edge facts; and whether the parse invocation/catch introduces canonical Exception edges and how those relate to NormalFlowView. These are investigation targets, not asserted observations. Java source alone cannot promise duplicate or clone-path edges, so no such edge is fabricated here.

No generated bytecode, compiler output, CFG observation, rejection layer, or acceptance claim is included. Root owns compilation and real graph review.
