## Context

[冻结对照](../../evidence/java-syntax-2026-09-27/em21-this-alias/report.md)的 `inline`/`checked` 由 `javac --release 8 -g:none` 生成接收者 `aload_0` 写非参数局部、再通过该局部调用或写字段。Jarde `build.rs` 已能根据 `reuse` 的变量身份、SSA 的读写与 `Declarations` 的作用域投影输出可编译的局部；`emit.rs` 可以输出 `this`。差距是同一个无效果别名在所有用途都可直接表述时，现有计划没有消去它。固定 JADX 的 `choose` 有两条到达定义，必须继续保留局部。

## Goals / Non-Goals

**Goals:** 仅在方法内唯一写入和所有读取的来源都可证时消去接收者的多余别名；保持表达式消费者和分支求值位置，尤其不把可能指向新对象的局部替换成 `this`。

**Non-Goals:** 通用复制传播、任意 SSA phi 消除、别名逃逸优化、字段/方法遮蔽的全局美化、无条件删除 `this.`、构造器和捕获外层接收者，以及跨方法/类的别名分析。

## Decisions

1. **复用既有同次身份事实。** 候选仅为非静态方法的非参数、非槽 0 局部：准确一次 `Store`，输入是准确槽 0 接收者的 `Load`，无额外计算、第二写入、复用变量身份冲突或未证 phi。按 `reuse` 的变量身份而非 JVM 槽号处理；读取点必须逐一证明仍读该写入的 SSA 值。仅接受已由 builder 支持的普通调用/字段接收者和 `Objects.isNull` 实参。`choose` 的 `this`/`new` 两个写入立即不合格。JADX 的变量化简结果仅作目标，Jarde 的判定以原 class 的 SSA/区域事实为准。

2. **在声明计划与读取投影之间传一份窄证书。** `Declarations` 为候选记录准确 `LocalVariable`、写入 BCI 和完整使用 BCI；同轮构造 AST 时只有证书命中的那次写入可不生成 `Declare/Assign`，每个命中读取生成现有 `ExprKind` 的 `this` 表达式并保留其 BCI 来源。对不匹配的使用、不完整区域或预算停止，整份证书作废，保留原局部投影或按原有机制拒绝。此处不增加新的跨方法 pass，也不修改 Java AST 类型。

3. **保持 Java 源级绑定。** 调用接收者可以保守输出 `this.touch()`，字段写入输出 `this.field = ...`；`Objects.isNull` 的实参必须保留 `this` 值，不能省成无实参调用。若现有调用/字段绑定证据不足以证明直接 `this` 与原目标相同，则不使用消除证书。直接复制 slot 0 的局部只是表现冗余，去掉它不允许移动或删除任何真实调用、分支或字段写入。

4. **完整源码与拒绝边界一起验收。** 冻结夹具三方全类与同一 Runner 以 Java 8 重编、`java -Xverify:all` 运行；Jarde 首片不再输出只读 `this` 别名，`choose` 仍有完整局部两臂赋值。另构造复赋值、条件来源、槽复用、其他读取、异常/区域缺失和预算停止的负例，要求不出现部分省略或改变身份。物理字节码/来源报告仍可查询。

## Risks / Trade-offs

- 若只按“局部曾被赋 `this`”判定，会错写 `choose`；唯一写入、全部读取的 SSA 来源及变量身份三重条件必须同时成立。
- 删除声明却遗漏一个读取会生成未声明变量；证书须在 AST 发布前覆盖所有用途，任何遗漏回退完整局部。
- 对 `this` 的调用可保留显式限定，先追求正确且少一个无用局部，隐式 `touch()` 的文风优化不加入首片。
