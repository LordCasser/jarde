## ADDED Requirements

### Requirement: 已证明的匿名实例初始化块恢复

当完整 Java 8 类源码中有一个唯一的直接返回匿名父类实例，且其物理构造器可完整证明为先调用准确父类构造器、再执行一个静态 `int` 字段赋值、最后返回时，系统 SHALL 在源级匿名体中按原顺序恢复该赋值的实例初始化块及其覆盖方法。该投影 MUST 保持构造时与调用覆盖方法时的效果次数和先后顺序；物理匿名 child 仍 MUST 可独立查询。

#### Scenario: 构造器中单个字段赋值

- **WHEN** 同包可拼写的 `Base` 被唯一的 `return new Base() { ... }` 分配，匿名 child 无捕获及自有字段，其构造器在 `super()` 后一次写入可拼写的根类静态 `int` 字段
- **THEN** 完整根类源码 SHALL 包含匿名体初始化块与覆盖方法，不再从根类引用物理 `Subject$1`，且原始、JADX、Jarde 完整源码 SHALL 在 Java 8 重编和 `-Xverify:all` 运行中呈现相同结果与效果顺序

#### Scenario: 初始化效果证据不完整

- **WHEN** 构造器多出第二个效果、额外字段或捕获、异常处理、非准确父类调用，或任一物理指令无法对应已恢复的初始化语句
- **THEN** 系统 MUST 保留物理匿名 child 路径，并 MUST 说明拒绝原因；不得发布仅部分内联的匿名体

#### Scenario: 受限运行停止

- **WHEN** 证明或呈现过程中预算不足或取消
- **THEN** 根类 MUST 保持未投影的完整源码，停止原因 MUST 可见，且不得残留已提交一半的初始化块或覆盖方法
