## Context

[巡查证据](../../evidence/java-syntax-2026-10-01/em17-slot-reuse-patrol/README.md)：A2 槽 2 先 `newarray int`（填充 `{side(),…}`）后 `newarray boolean`（`new boolean[3]`）；读取段分别为增强 for 与 `f[i]=true`/`f[1]` 读，不交叠。主线输出单声明 `int[] local2` + 后续 boolean 赋值，不可编译。源码上这是两个作用域局部（javac 槽复用的常规产物）；正确呈现是按定义分段声明。既有数组证书（嵌套/布尔/窄存等）按**单定义**呈现，不触此形态。

## Goals / Non-Goals

**Goals:** 同槽、不同元素类型、读取段不交叠的多数组定义按段呈现（每段自有声明与类型）；A2 整类可重编、行为一致；A1 与单定义/同类型多定义逐字不变；交叠别名（真实跨段读取）保持现有行为。

**Non-Goals:** 证明层改动（段划分按既有 SSA/位置事实）；交叠读取的重命名机制；非数组类型的槽复用重声明（caught 值另片；其余类型随后按需）；`Object` 语义。

## Decisions

1. **呈现层分段，判据用既有事实。** 段边界 = 定义 store 序；段内读取集合经 SSA（每读取值的 def 即所属段定义）；两段读取集不相交（含 phi 不跨段）才分段，否则维持现行为。类型取各段定义值的 `written_type`（数组通道已有）。
2. **呈现形态取分段子句。** 每段声明置于该段首读/首存之前，沿用现有声明提升位置规则；不为分段引入新 AST 节点（文本层面 `boolean[] local2 = new boolean[3];` 的重新声明即合法 Java——同名同作用域重复声明不合法时用段内新名，实现者按编译事实选择并在测试钉死）。
3. **拷贝别名**：`local0 = …; local2 = local0` 的消除是分段呈现自然覆盖时才发生（段一声明直接命名填充表达式）；无独立机制。

## Risks / Trade-offs

- **误分真别名段** → 判据要求读取集不相交且无跨段 phi；"交叠读取"负例钉死维持现行为。
- **重复声明不合法 Java** → 决策 2 的回退（新名）由编译事实裁决，测试断言 `javac --release 8` 通过。
- **与 caught-value-argument-typing 冲突** → 串行实施（后者先行合入后 rebase 本片）。
