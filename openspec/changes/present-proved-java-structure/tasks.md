- [ ] 3.3 循环测试位（`while` 头、`do-while` 闩锁）的分支链写成复合条件。链上每条分支的条件各自是可证比较；`&&` 形状：每条分支的假边都离开循环（汇到同一出口），最后一条的真边进入循环体；`||` 形状：每条分支的真边都进入循环体，最后一条的假边离开。左结合、按字节码顺序拼 `c1 && c2` 或 `c1 || c2`。同一头部里混用 `&&` 与 `||`、某条分支两边都不离开测试链、或任一条件证不了时，保持今天的整段引用，不得猜优先级或加括号。这不是把两个 `if` 折叠成 `&&`：值位与 `if` 位的折叠仍是非目标；循环测试位的分支链只有这一个结构化拼写（`while(true)+break` 是另一种字节码）。需要条件表达式支持 `&&`/`||` 两种二元操作，仅在循环测试位使用。验证：`andWhile` 是 `while (arg0 > 0 && arg1 > 0)`，体三条语句仍在；`orWhile` 是 `while (arg0 > 100 || local1 > 5)`；一条单条件循环不变；一条混用 `&&`/`||` 的循环仍整段引用（P02/P04）。
