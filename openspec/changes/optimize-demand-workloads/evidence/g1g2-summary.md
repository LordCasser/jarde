## 准入矩阵（每项：处置 / 关键证据 / 上界 / 与它项是否重叠）

| 项 | 处置 | 关键证据 | 理想上界 | 重叠 |
| --- | --- | --- | --- | --- |
| O1 容器定向访问 | **否决新立项**（维持已交付，归归档 `bound-container-lookup`） | 定向 2+2（728 B）对整树 26+25（7866 B）；未搜索 sibling 物化恒 0 | 每次省 7138 B | 与 O5 的容器层是**同一交付物**（两份证据的 W5 网格逐项相同）→ 只计一次 |

**5% 核对**：`1/(1−p)` 示例（p=0.05 → 最多省 5%；p=0.05、s=4、h=0.01 → 只省 2.7%）；O2 的窗口份额上界是 **0.5%**（要 5% 需 13.8 ms），故本项**只作工作量准入，禁止发布加速结论**。

## 登记（3.2）

准入项登记为独立变更 **`reuse-selected-class-read`**（已建项并通过 strict）：capability delta = `facts-cache`（ADDED「A verified definition read is reusable within explicit bounds」+ MODIFIED 身份表与两处既有 scenario）与 `artifact-snapshots`（MODIFIED 有界读取，新增受信读取复用入口）；直接路径 = `src/facade.rs` 的身份绑定读取与 `crates/jarde-jvm/src/providers.rs::read_definition_class`；回退责任 = 无 store / 满容量 / 异声明条目 / 取消耗尽 / 身份不符逐条走直读，语义回归撤回该独立提交。**O1 仍由归档 `bound-container-lookup` 唯一负责**；O3 不得越过子 spec；O4/O7 不得越总额度与窗口门禁；本阶段无产品实现。

## 实验（3.3，单因素、可撤销）

两臂同一二进制，唯一变量 `JARDE_OPTIMIZE_READ_REUSE`（默认关、普通构建中不存在），11 格 × 2 臂 × **10 次交错**（220 进程），fixture 与 bcprov（`5329ddefb3c92927`）。

| 形状 | 前后（中位，配对更快次数） | 计数 |
| --- | --- | --- |
| W1 第二次请求 | 66 → **50 µs**（9/10） | `class_materializations` 1→0 |
| W2 控制重问 | 20 → **8 µs**（10/10） | 9→8 |
| W3 逐方法臂 | 2178 → **1764 µs**（10/10） | 36→0 |
| W5 往返 | 498 → **416 µs**（9/10） | 10→1 |

准备段与 `class_preparations` 不变；驻留 +2,056 B（1 定义）…+8,916 B（8 定义），RSS 无可区分差；容量退化（`none` 拒绝 +10 次后照常读取、`e1` 全拒绝、`tiny` 命中读取本身、容器层被饿死时读取复用仍生效）；负向：跨 snapshot 判别性用例第二步**未命中**、24/24 结果指纹（去 `usage`/`elapsed_millis`）相同；`w5-sweep` 与窗口层记**未证实**。实验已**全部还原**（`git diff` 为空），原型不在树中。

## 决定（3.4）

**实施（有条件）**：依据工作量与契约层（重复读取被删除 + 结果不变 + 干净回落）；条件已写进 `reuse-selected-class-read`（定义 spec delta、只作工作量主张、回退逐条演练、不新增依赖/线程/unsafe/淘汰）。所需能力**已有**：同一 `FactsCache` 的双界与满则拒绝、`Arc` 句柄、`FactsIdentity`、不可变快照与受信摘要、`Budget` 唯一附着点；实现只用 `std`，**无新依赖、无新许可**。**没有原型成为默认策略**。

## 未确认项（不得读作已测）

① 一次受信读取自身的耗时与 `s`、`p` 分量（只有 0.5% 的窗口上界）；② 紧预算下命中少计费可能改变完成度（须进 G3 冷/热对照，已写进该变更的 4.1）；③ `retained_bytes`→RSS 换算；④ 相同内容的两个 snapshot 共享同一 snapshot 身份时的行为（只测了不同 snapshot 必须不命中）；⑤ O3 的子 spec 与真实小页工作负载；⑥ fixture 小请求与窗口层读数落在离散度内，属噪声。
