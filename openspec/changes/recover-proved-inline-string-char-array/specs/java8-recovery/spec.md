## ADDED Requirements

### Requirement: 保留身份的内嵌字符数组 String 构造

对于 Java 8 类中直接返回的 `new java.lang.String(char[])`，当唯一字符数组实参的完整初始化、外层对象构造与最终返回均由同次物理证据证明且求值顺序闭合时，类源码视图 SHALL 输出保留显式 `new String(...)` 的完整 Java 表达式。输出的完整类源码 MUST 可由 Java 8 重编，并在验证运行中保留原 class 的字符内容与新对象身份；不得用同内容字符串字面量替换显式构造。任何关系、效果、异常范围、来源或预算证据不完整时，视图 MUST 保留可定位的物理回退，不得发布只含部分数组或构造的表达式。

#### Scenario: 直接初始化字符数组并构造 String

- **WHEN** 唯一 `char[]` 按顺序初始化为 `'a'`、`'b'`、`'c'`，仅作为准确 `java/lang/String.<init>([C)V` 的实参，并直接返回该新对象，全部证据完整
- **THEN** 完整 Jarde 源码包含内嵌字符数组和显式 `new String`，Java 8 重编及 `-Xverify:all` 输出 `abc`，且与同内容字面量的 `==` 为 `false`

#### Scenario: 初始化数组先存入局部

- **WHEN** 已证明的 `char[]` 初始化先存入一个局部变量，再传给 `String([C)V`
- **THEN** 原有局部数组及显式构造源码保持可编译，结果身份仍不同于字面量

#### Scenario: 实参或构造关系未闭合

- **WHEN** 数组被额外读取或写入、存在未知元素效果、构造器 owner/描述符不匹配、数组与构造使用不在同一可证明顺序或异常处理范围不一致
- **THEN** 不得把该数组内联进外层 `new String`，也不得把对象折叠为字符串字面量；拒绝原因与物理来源保持可见

#### Scenario: 预算或取消中断

- **WHEN** 共享预算或取消在数组、构造或输出证明期间停止
- **THEN** 不发布半份内嵌表达式，报告执行状态保留实际停止原因与已知物理指令
