## Context

见 [冻结对照](../../evidence/java-syntax-2026-09-27/package-info-basic/report.md)。类文件读者已提供物理头、注解和来源；`class-source` 已能拼写 `@java.lang.Deprecated`，但现有装配先写 `package p;`，再写类注解和普通接口头。JADX 在 `ClassGen.makePackageInfo` 使用“注解在先、包声明在后”的输出路径，其 `ClassNode.processSpecialClasses` 以简单名与空成员判定，条件比本项目所需的准确证明宽松。

## Goals / Non-Goals

**Goals:** 在现有类级源码装配路径上增加一次有界的特殊源文件投影；把物理类的包注解与包声明作为一个整体输出，并让完整源码可重编且保留来源。

**Non-Goals:** 不增加新的 classfile 解析器、宿主 API、导入优化或通用注解恢复机制；不覆盖默认包、非 Java 8 版本、类型注解、未知成员或无法完整拼写的注解；不把原 jar 的运行时验证替代源码重编。

## Decisions

1. **在类级装配入口证明候选，再使用既有注解拼写。** 从同次已确认的 classfile 事实构成严格候选：自身内部名恰为合法非空包路径下的 `package-info`，版本为 52.0，标志为标准 `0x1600`，父类为 `java/lang/Object`，接口/字段/方法表完整且为空，唯一类属性是一个完整 `RuntimeVisibleAnnotations`，其中唯一且空值的注解是 `java.lang.Deprecated`，来源完整，预算与取消状态允许提交。首切片拒绝 `SourceFile`、不可见注解、多个注解和其他注解，避免依赖未证明的 annotation target/retention 元数据；后续扩大范围须单独证明。类名、注解或成员表有任何不确定时不进入投影。JADX 的判定与测试可作定位参考，不能充当充分条件；另一备选是只按简单名及空成员判定，这会把非标准字节误写为 Java 源包声明。
2. **原子装配特殊源文件。** 候选通过后在现有 `class-source` 的类级输出分支复用 `with_annotations` 的注解结果，将注解置于 `package` 前，省去普通类型头、花括号和成员段。先构造完整文本与来源，再替换展示结果；若中途失败则返回原物理展示及明确拒绝，不发布半个包声明。备选是另造 package-info IR 或后处理替换字符串，前者超出单点需求，后者无法保持来源与拒绝边界。
3. **保持事实、恢复和验证分层。** classfile 解析只读取原始事实，Java 8 方言条件由候选证明使用，源码恢复只生成显示文本；不会执行目标代码或从外部下载依赖。验收先以冻结 class 字节与 `javap` 核对输入，再用完整源码 Java 8 编译和 `-Xverify:all` 运行确认语义。JADX 源码和算法是对照，不依赖其库；避免引入许可与维护负担。

## Risks / Trade-offs

- [过严证明使合法变体暂时仍无法投影] → 首切片只宣称冻结标准形状，其他形态留在 EM-04 单元扩验；拒绝保留事实，后续由证据放宽。
- [包注解位置或来源偏移错误] → 对完整输出和源跨度增加直接断言，并运行包反射读取。
- [类级注解包含超出当前写出能力的值] → 整体拒绝投影，避免只输出部分注解而改变包语义。
- [预算/取消发生在文本构造中] → 构造完成前不提交候选，保留原有取消与低预算行为。
