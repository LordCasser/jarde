# Hoisted iterator internal-test candidate v2

This directory contains a private, tests-only patch against the shared `crates/jarde-java/src/build.rs` snapshot pinned in `pins.json`. It keeps the existing `analyze_own_grid` entry point as a wrapper and adds `analyze_test_method` for direct analysis of a named method from a single frozen class. The patch does not change production code and does not add a fixture class.

The candidate uses two real byte inputs. `UpstreamNestedLoops.class` is the frozen `cf11.UpstreamNestedLoops.test(Ljava/util/List;Ljava/util/List;)V` target. The pinned same-IR diagnostic records the init/test/next stores and loads as one `LocalVariable { slot: 5, index: 0 }`, the declaration placement and Iterator-typed owner row at path `[1]`, the header phi with its self edge, and a later block with three matching iterator phi operands alongside three `None` uses. That block also has a replaced phi for `Local(6)` with no iterator operand or uses. `Scope.class` supplies a separate real slot-reuse method whose slot 3 has distinct debug-local identities at BCIs 8 and 17.

The declaration-gate test exercises the production helper with these real planned facts while varying only its statement-list and ownership inputs: a current-list blank declaration, the same owner declaration absent from the nested list, an absent owner row, incomplete placement, a non-Iterator owner-row type, an un-emitted declaration, an invisible owner path, and a budget Stop on the second local-identity check. The split-slot test uses the real `Scope.reuse(ZI)I` plan and refuses a sequence whose slot changes identity. The phi-gate test checks the real self edge and repeated block-97 operands, verifies the unrelated local phi is not part of the iterator proof, then checks acceptance, an out-of-set physical reader, and a budget Stop.

These are internal gate tests, not public-output or runtime-oracle tests. No candidate source was compiled, no Rust tests were run, and no Java/JADX/CLI/toolchain command was run. The proposed helper refactor and all candidate assertions still require root review and normal validation. The previous v1 preparation remains untouched at `/private/tmp/jarde-hoisted-iterator-regression-prep-luna-v1`.
