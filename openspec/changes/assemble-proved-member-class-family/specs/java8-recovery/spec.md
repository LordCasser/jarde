## ADDED Requirements

### Requirement: 已证明的命名成员类家族源码

对选定 Java 8 根定义，系统 SHALL 仅在非静态命名成员关系、物理定义、构造捕获和所有被投影使用均有完整证据时，将该成员写为根类内部的 Java 声明，并保留原始根/成员定义及方法报告。恢复文本 MUST 区分捕获的词法外层实例和同类型的显式参数；MUST NOT 根据二进制名中的 `$`、合成字段名、类型相等或单侧 `InnerClasses` 推断关系。任何证明缺失、解析歧义、预算停止或取消 MUST 保留已取得的物理事实和明确的部分/拒绝状态，不得省略仍可观察的字段、参数、调用或方法体，也不得宣称完整 Java 家族。

#### Scenario: 非 public 成员声明与捕获接收者

- **WHEN** 选定根类和唯一成员定义的双方嵌套属性一致，成员的唯一构造器把首个隐式 Outer 参数捕获到唯一字段，成员方法同时读取该捕获值及同类型的显式 `other`
- **THEN** 根类文本 SHALL 内嵌成员声明，按真实成员可见性拼写源码，在成员体区分 `Outer.this` 与 `other`；完整输出连同已提供的顶层依赖 SHALL 经 Java 8 重编并与原 class 的值、副作用及异常行为一致

#### Scenario: 已证明的隐式构造参数

- **WHEN** 同一家族内的构造调用、捕获参数、唯一字段写入、空值检查及普通实参次序可完整证明
- **THEN** 源码 SHALL 在合法词法位置呈现成员构造调用，隐藏仅属编译器捕获的字段、参数和写入；原物理 descriptor、构造器 BCI、字段 BCI 和调用点 SHALL 继续在报告中可追溯

#### Scenario: 同类型显式参数不得冒充词法实例

- **WHEN** 成员方法既接收一个与 Outer 同类型的普通参数又读取捕获字段
- **THEN** 普通参数的字段/方法访问 MUST 保持原接收者，只有经捕获值流证明的访问可呈现为 `Outer.this`；测试结果 MUST 能区分两者

#### Scenario: 关系或捕获不闭合

- **WHEN** 根与 child 嵌套记录冲突、定义缺失或含糊、存在 local/anonymous 身份、捕获字段有额外写入/未知使用、构造器首参和字段值不一致，或调用/读取不能归入唯一捕获
- **THEN** 系统 MUST NOT 发布省略这些物理构件的可编译家族文本；受影响区域 SHALL 有拒绝原因和原始身份/来源，未受影响的同类成员不被伪造或静默丢弃

#### Scenario: 非本阶段的 super 方法桥

- **WHEN** 成员方法调用的静态合成桥在 Outer 内执行对其父类的 `invokespecial`，而当前没有完整的桥定义及调用点闭包证明
- **THEN** 本要求 MUST NOT 把该桥猜为 `Outer.super` 或从家族文本中静默删除；报告 SHALL 保留物理桥和调用点，并明确完整家族投影未闭合

#### Scenario: 有界请求与独立方法入口

- **WHEN** 家族发现或成员恢复触发预算停止/取消，或者调用者只请求一个物理方法的恢复
- **THEN** 已取得的来源、覆盖和执行状态 SHALL 如实返回；方法请求 MUST NOT 为了词法源码自动恢复整个家族
