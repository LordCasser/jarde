## Context

`class-source` 已由方法 access flags 与描述符证明 `T...` 声明；方法体的末参仍是 JVM 数组。`jarde-java` 的数组构造证明可以把闭合的 `new T[]{...}` 交给表达式树，`CallTarget` 仅保留 CP 符号引用，不声明 callee access flags。当前 `present-proved-java-structure` 的 2b.7 明确保留显式数组；本变更只在新增的绑定证明成立时收紧该输出，不修改通用数组规则。

## Goals / Non-Goals

**Goals:** 对同一选定物理类内、可证明唯一绑定的可变参数调用实现最小闭环；让数组元素、调用和被隐藏的显式数组语法仍带准确来源。

**Non-Goals:** 跨类依赖递归解析、任意继承树中的重载证明、寄存器/局部数组反向内联、将所有 `new T[]{...}` 消成 varargs、任意 `invokedynamic` 参数重写。没有证明时现有显式数组源码仍是合格输出。

## Decisions

1. **在调用装配处选择源级形式。** 先由现有值渲染与 `arguments()` 完成物理实参类型约束，再检查末参是否为现有 `NewArray` 且含已证明的完整初值；仅改变 `Call` 的实参数组，不改字节码事实或通用数组构造器。JADX `MethodInvokeVisitor` 的 varargs 标记和 `InsnGen.processVarArg` 提供模式参考；Jarde 增加其缺少的源级绑定门。
2. **只读复用同类成员表。** 对 CP 的精确 owner/name/descriptor 在本次已选物理 `ClassMembers` 中找唯一声明并查 `ACC_VARARGS`。初始正例仅允许本类调用、无同名竞争声明、已证直接父类为 `java/lang/Object`；其他继承/外部目标保持显式数组。这样无需给每个 `CallTarget` 增加猜测性 flags 或再读全局索引。
3. **拒绝改变 Java 可变参数调用模式的单元素。** 一个 `null` 或其源类型可赋给整个数组的元素，可能在展开后被当作固定数组实参；先保留原显式数组。只有元素类型与目标组件兼容、按顺序一次求值、展开不引入新重载候选时才能改写。
4. **来源附着于调用表达式。** 原数组分配和逐元素存储的 BCI 作为派生来源挂到被展开调用/对应元素，不因源文本中不再显式出现 `new T[]` 而丢失；物理报告不改。

## Risks / Trade-offs

- `[继承/跨类重载未知]` → 保守保留显式数组，后续独立任务可扩大证明范围。
- `[数组元素有可观察效果]` → 使用现有闭合数组初始化与调用实参顺序证明，三方运行核对效果次数；不能证明即不展开。
- `[JADX 正向断言只比较文本]` → 本变更额外要求 Java 8 重编、执行和 `-Xverify:all`，并保留普通数组与歧义负例。
