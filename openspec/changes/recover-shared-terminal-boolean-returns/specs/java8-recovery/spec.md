## ADDED Requirements

### Requirement: 共享双终结返回的布尔条件

对于 Java 8 布尔返回方法中可证明的有界无环条件图，若全部正常路径只到达各自返回 `true` 或 `false` 的两个终结块，系统 SHALL 生成可重编译且与原字节码等价的 Java 返回语句。生成结果 SHALL 按真实分支极性惰性执行每项条件，保留可观察操作、异常及求值次序；每个被折叠的真实指令位置 SHALL 可在来源映射中追溯。

#### Scenario: 两组可空字段比较共享布尔返回
- **WHEN** Java 8 class 的布尔方法沿多个 `ifnonnull`、`ifeq` 和纯转接块完成两个可空字段比较，所有正常路径汇入共享的 `iconst_1; ireturn` 或 `iconst_0; ireturn` 终结块
- **THEN** 系统输出无重复物理块认领的 Java 方法，完整类以 Java 8 重编成功，null/非 null 的各路径值和调用次数与原 class 一致，所有真实 BCI 有来源

#### Scenario: 出口或类型证明不闭合
- **WHEN** 候选条件图存在第三个可达返回目标、返回值并非可证明的布尔 1/0，或方法声明并非布尔返回
- **THEN** 系统 SHALL 拒绝把该图写成布尔返回表达式，且 SHALL NOT 只提交其中一部分条件或丢弃原指令来源

#### Scenario: 图外入口或效果顺序不闭合
- **WHEN** 某个内部条件/终结块有额外入口，存在回边、不可表示的异常边、条件之间独立的可观察语句，或无法证明 taken/fallthrough 与惰性求值顺序
- **THEN** 系统 SHALL 保守拒绝折叠该图，保留字节码引用及停止/覆盖信息，而不以共享可达性猜测条件极性

#### Scenario: 预算或取消停止
- **WHEN** 图发现、证明或发射时预算耗尽或任务被取消
- **THEN** 系统 SHALL 报告相应停止状态，SHALL NOT 发布只包含部分图的 Java 返回语句或部分来源映射
