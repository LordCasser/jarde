## Context

[巡查证据](../../evidence/java-syntax-2026-10-02/nested-name-spelling-patrol/README.md)：V1 两处 `$` 拼写（参数类型/枚举常量限定）。既有约定核对：匿名类合成名 `C1$1` 在分离 family 呈现中**有意保留**（`C1$1 local1 = new C1$1(arg0);`——CT-1 命名家族、可编译：类名声明同拼写）；enum 折叠文本内常量自身简单名。**第一个取证义务**：定位类型引用拼写的统一出口（grep 呈现层类型名转换——平台限定名 `java.util.List` 的点拼与包级简单名的分派处），确认 (a) 嵌套 `Outer$Inner` 当前如何直拼、 与匿名合成名 `X$N` 约定的共存边界（`N` 数字后缀不转换；仅字母 `Inner` 段转换）。

## Goals / Non-Goals

**Goals:** 自嵌套简单名、跨类点分；V1 可重编；合成名与既有约定零回退。**Non-Goals:** import 引入（按既有全限定呈现）；深层链 `A$B$C`（点分全链，验一形）；本地类命名（Java 8 `1$Local` 形——登记现状）。

## Decisions

1. **单点转换**：在既有类型拼写出口（非各调用点）实施：常量池名 split `$`——尾段为数字（`X$1`）保持；`Outer$Inner` 时自嵌套（Outer==当前类）→ `Inner`、否则 → `Outer.Inner`（多段全点分）。仅源码语法位出口，方法注/描述符注释（`// @method (LV1$Op;I)I`）不动。
2. **验收锚定**：V1（重编+运行一致）+ 变体（跨类嵌套引用 `Other.Inner`、深层 `A$B$C` 一形、`X$1` 合成名逐字不变）。
3. **边界**：匿名/局部类合成名与 enum 折叠家族 diff 逐字不变；462 工件级 before/after 扫描（呈现层改动面）确认差异仅在嵌套形态。

## Risks / Trade-offs

- **与合成名判定冲突** → 尾段数字判据先行；`X$1` 负例钉死。
- **跨类 Outer 不在快照** → 点分拼写仍合法源码（编译需该类——与包级类同境），呈现层不涉证明。
