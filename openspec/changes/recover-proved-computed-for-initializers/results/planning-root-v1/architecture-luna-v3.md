## Minimal reuse strategy: keep three doors separate

1. **Computed initializer:** retain all current natural-loop/latch/phi/update/invariant checks. Replace only the final `Push(Int)` producer restriction with a bounded proof of the exact preheader value chain needed here: one int argument `Load`, one `Push(Int(1))`, one int `Sub`, then the existing induction-local `Store`; SSA operands/defs must prove that exact dependency and every intermediate must have its one expected consumer. Reuse its already-built statement at `init_bci`; do not synthesize an expression walker or move unrelated work. This deliberately excludes calls, field/array reads, stores, division, and other effect/exception-producing operations. Keep the exact statement identity Builder uses and its “only empty declarations intervene” condition.
2. **Certified return read:** compute `loop_terminal_returns` once, before `prove_for_header`, with the same `blocks`, `exit_node`, and `frame`; pass that set to the existing scan and reuse it for `Frame::loop_body`/coverage. Permit only reads of the induction slot in those exact certified leaf blocks. Continue rejecting all out-of-loop writes and every other out-of-loop read. Do not add the leaf to natural-loop blocks or alter ownership.
3. **`ForHeader` tail origin:** let the existing final direct no-join `If` shape be considered when a `ForHeader` exists only if one arm is the exact single certified return leaf and the other arm owns the exact `proof.update_block`. Require its final two SSA instructions to be `proof.update_bci` plus the unique transfer at BCI 25; retain current natural-loop header/unique-latch/non-irreducible checks, one normal successor to header, exact one canonical outgoing normal edge, and no return-leaf outgoing edge. Append only that transfer BCI as a derived origin. Preserve the current final-`Straight` path unchanged. No region is moved or reparented.

## Refusal boundary and adversarial cases

- Do not hoist an initializer across any executable statement, assignment, call, or exception edge; Builder's existing gap may contain only empty declarations. Preserve Java evaluation order and exactly-once evaluation. The narrow `arg - 1` chain itself cannot throw; reject shared/multi-use intermediate values unless the existing builder proves one materialized evaluation. Never duplicate a call, potentially throwing operation, or value computation into both initializer/body.
- Keep all writes to the induction slot outside the loop/preheader rejected; retain current loop-body writes-to-slot and invariant-local write gates. Reject a second update, multiple/irreducible latches, varying bound, post-loop value use, non-unique phi/input, extra loop test, a return leaf with another predecessor/successor, or any tail arm that is fallback/nested/multi-exit rather than the proved direct return/update pair.
- Existing negative controls worth preserving: `tests/p3_for_latch.rs` (`observedAfter`, `twoUpdates`, `varyingBound`, `noUpdate`), `tests/p3_loop_transfers.rs` continue ownership, `tests/p3_array_foreach.rs` refusal cases, and `tests/p3_arraylength_loop_condition.rs`'s throwing condition must remain unchanged. Also retain budget/cancellation behavior of `prove_for_header`.
