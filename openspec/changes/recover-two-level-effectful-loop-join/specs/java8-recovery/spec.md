## ADDED Requirements

### Requirement: 二层条件分支内的带效果双出口循环准确汇合

当一个 Java 8 方法的外层分支含有内层条件分支，内层一臂给局部结果赋值，另一臂执行已受证的带效果双出口无限循环，且循环两出口与兄弟臂只在同一内层 join 汇合时，系统 SHALL 仅在控制流、三份局部值、效果次数、内外边界和物理来源闭合后输出结构化 Java 源码。源代码运行 MUST 与原 class 在每条完成路径上一致；证据不足时 MUST 保留物理引用，不得把效果调用移动到未执行路径。

#### Scenario: 空臂与两个循环出口汇成一个值
- **WHEN** 输入是冻结的 `TwoLevelIf.pick`，分别传入 null、空数组、含 3 数组和不含 3 数组
- **THEN** Jarde 完整 Java 8 类源码 SHALL 重编，并在 `java -Xverify:all` 下与原 class、固定 JADX 逐项输出 `-1:0 / -1:0 / 3:0 / 8:1`；`pick` 无 `@bytecode`，循环和两个 join 的物理指令各有唯一可解释归属

#### Scenario: 额外入口或不同出口拒绝折叠
- **WHEN** 循环有额外入口、两个出口不再到同一内层 join、空臂绕过该 join、join 有第四条正常入边、效果调用次数变化、异常边进入候选，或三来源值关系不闭合
- **THEN** 系统 MUST 不发布该二层循环结构，保留对应 BCI 的拒绝来源，不得省略、提前或重复效果

#### Scenario: 预算与取消不发表半份结构
- **WHEN** 证明或输出在预算耗尽、取消时中断
- **THEN** 系统 MUST 返回停止状态且不发布部分源码或部分来源图

#### Scenario: 已受证单层形态不回归
- **WHEN** 输入是已受证的顶层带效果双出口、单层外部 `if` 及单出口循环臂
- **THEN** 既有可编译源码、运行语义和安全拒绝边界 SHALL 保持
