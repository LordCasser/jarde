## ADDED Requirements

### Requirement: 已证明的带效果双出口循环保持每条退出路径的效果

当 Java 8 方法含一个单入口、单回边循环，其头比较失败臂执行独占效果后退出，另一个体内比较臂不执行该效果而直达相同唯一后继时，系统 SHALL 仅在完整控制流、SSA 局部值和区域所有权证明闭合后输出 `while (true)`、体内条件和对应的 `break`。生成源码 MUST 保留头比较次数、每条路径的效果调用次数、局部结果和共同后继只执行一次。无法证明时 MUST 保留物理拒绝，不得把体内退出改走效果臂。

#### Scenario: 越界退出执行效果、命中退出跳过效果
- **WHEN** `EffectfulExits.pick` 的头部越界臂执行 `cost(7)` 并保存结果后退出，而体内命中 `3` 时直接退出，两臂只有 BCI 35 作为共同后继
- **THEN** 原 class、固定 JADX 和 Jarde 的完整 Java 8 源码重编并以 `java -Xverify:all` 运行，空数组、命中 3、未命中直至越界三组结果依次为 `8:1`、`3:0`、`8:1`，Jarde 方法无 `@bytecode`

#### Scenario: 额外边或值来源不闭合
- **WHEN** 效果块或直达出口多一个入边、两出口目标不同、存在异常 handler/额外回边或调用、SSA 在共同后继有未证定义/消费者，或预算/取消中断证明
- **THEN** 系统 MUST 不发布这个完整循环，保留拒绝与物理 BCI/停止状态，不静默省略效果或重复执行

#### Scenario: 已支持的纯双网关与普通循环不回归
- **WHEN** 输入是已证明的双纯 `goto` 出口或单出口 while/do-while 循环
- **THEN** 既有区域所有权、来源及 Java 8 运行行为 SHALL 保持；本项 Endless 准入不替代它们的证书
