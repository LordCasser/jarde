# Private If-arm join whole-class replay draft

These are private adaptations of the actual For files `prepare-candidate-root-v1.py` and `verify-candidate-root-v1.py`. They retain the 57-command replay: original class runs on javac 8/23, JADX default/none comparisons, Jarde default/all renders, and complete-class compile/run legs. The verifier keeps the existing default/all text and source-map equality checks, method identity and physical-BCI/source-owner validation, exact Java 8 source-span validation, and full-class runtime comparison. It also compares the If candidate to the accepted For bundle: prior owner/provenance pairs must remain for every old plain/postfix method, and postfix class text plus all source maps must match the accepted For outputs exactly, preserving the prior For@20 body and spans.

Both scripts require `--source-base` as a lowercase 40-hex value. The collector binds the explicit CLI path/hash, CLI mode 0555, metadata path/hash/schema/CLI identity, build execution path/hash/schema/version, validation runner path/SHA, guarded template path/SHA, frozen CLI record, source-base value, `uncommitted_if_arm_join_product=true`, and all live product/test/literal-include pins. The verifier repeats those bindings and independently verifies every raw command and output inventory. It does not hardcode or guess a future metadata SHA; root passes the actual CLI and metadata SHA values after the new validation run.

The previous For bundle is independently pinned by its already accepted acceptance record, manifest, inventory, and complete file closure. The collector records this baseline in the new manifest; the verifier rechecks it and compares prior source-origin identities. It never replaces or edits the historical For bundle or its acceptance record.

Before root runs, copy these reviewed files into the new change results directory as `prepare-candidate-root-v1.py` and `verify-candidate-root-v1.py`; their manifest/acceptance collector paths are bound to that location. Then run the collector with explicit `--source-base`, `--cli`, `--cli-sha256`, `--metadata`, `--metadata-sha256`, and `--build`; run the verifier with the same `--source-base`, manifest path, and exact build execution path. Outputs are exclusive under the new change's `candidate-whole-classes-root-v1` and `candidate-whole-classes-acceptance-root-v1.json`.

No collector, verifier, Cargo, JDK, Git, or CLI was run for this draft. The new If metadata does not exist yet; no SHA or success result is claimed.
