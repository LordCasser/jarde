## Context

见 [proposal.md](proposal.md) 及 [固定类物理阻碍](../../evidence/java-syntax-2026-09-27/cf08-endless-loops/not-indexed-fixed-triage-2026-09-28.md)。当前 `effectful_dual_exit_loop` 已证明单层和二层三来源双出口，`continue_inner_join_arm` 能把单块尾接入外层分支。固定 class 的正常 CFG 恰有内层三来源 join 64 与外层 join 69，但现有值门只接受单次调用结果和本 join 立即读取；构造对象与体内虚调用因此被拒绝。原/JADX 完整类可编译运行，Jarde 当前源码不可编译。输入来自同一固定 Java 8 编译器产物，不执行目标代码作为恢复分析的一部分。

## Goals / Non-Goals

**Goals:** 保持已验收双出口循环的控制流、来源和原子停止契约；在同一 Region 候选内闭合固定类的构造对象、谓词调用和二层 SSA 值转送，最终用完整类三方执行验收。

**Non-Goals:** 任意构造器、任意虚调用链、任意深度 phi 转送、异常化循环和不受证的另一种 lowering 不因这一切片开放。其余固定测试或其他模块债务独立登记。

## Decisions

1. **在现有候选中证明两种出口生产者，不建立新的循环 IR。** 保留准确三块自然循环、单闩锁、两出口和三入边 join 的物理 CFG 门。已有 `Push→Invoke→Store→Transfer` 分支继续通过。实查固定同轮 SSA：BCI 25 `new` 写栈值 v28；28 `dup` 读 v28，写 v29/v30；29 `ldc` 写参数 v31；31 `invokespecial File.<init>(String)` 读 v31/v30，写初始化后的栈值 v32；34 `astore` 读 v32，写 local2 v33，v33 唯一进入 64 的 phi。v29 是 `dup` 留下的第一副本，SSA 将其初始化折叠到 v32，故 v29 **没有显式 use**。新增有界形态同时核精确 opcode/栈槽、构造调用目标、v28→v30→v32→v33 的定义/唯一消费和 v29 无额外消费者；不把 v29→store 伪称为 SSA 显式边，也不按局部槽号推测对象身份。
2. **把循环体谓词作为受限有序效果链。** 实查 BCI 41 `aaload` 写 v36→42 `astore` 写 local2 v37；43 `aload` 读 v37 写 v38→44 `File.getName` 读 v38 写 v39；47 `ldc` 写 v40，49 `String.equals` 读 v40/v39 写 v41，52 `ifeq` 唯一消费 v41。仅准入这条准确接收者、实参、结果链；按原 BCI 顺序留在循环体，不把调用提升到测试头或桥块。现有无调用分支保持原门。参考固定 JADX 测试的循环结构目标，但不用 JADX 的文本断言替代原 class 运行语义。任何额外调用、别名消费者、异常边或非唯一分支输入继续整体拒绝。
3. **为本固定一跳值转送证明两个 phi 的关系。** 实查 SSA：内层 local2 的 BCI 12 null v43、构造对象 v33、数组元素 v37 在 64 合流为 v7；64 仅执行 `goto 69`，v7 唯一用处是 69 的 phi 输入；外层 68 null v26 提供另一个输入，phi69 产出 v4。69 判空、73 `deleteOnExit` 和 77 返回均读取 v4。只有当 phi64 在唯一正常后继 69 的入口恰好作为 phi69 的一个输入，且其余输入/使用闭合，才允许现有尾续接证书运行。不能把 `slot=2` 相同或源码变量名相同当作值证明。中间块若携带效果、多前驱或额外消费者则拒绝。
4. **原子提交和完整类验收。** Region 候选先在受预算的只读检查中闭合 CFG、SSA、效果和来源，再进入既有 Builder checkpoint；必要时仅修正此结构的局部范围/呈现。以固定输入、原/JADX/Jarde 完整源码的 Java 8 编译和四个运行输出验收，并核对负例的 JVM verifier 有效性。拒绝不发布部分源码/来源。

## Risks / Trade-offs

- [SSA 将初始化对象的别名折叠而无法直接以 `dup` 追踪] → 从物理指令和同轮 SSA 栈槽双向核实；证据不足保留拒绝，绝不扩大到同槽推断。
- [谓词链的无害变体过早被拒绝] → 当前只闭合固定形态及等价已验证变体；另建独立证据后才扩展，不让本次验收依赖猜测。
- [两层 join 虽形状闭合但 Builder 局部声明越界] → 在同一候选的 checkpoint 内检查完整源码编译和每条物理来源；只做必要的范围修正，不引入通用局部绑定机制。
- [JADX 文本通过但行为偏移] → 使用原 class 为语义基准，固定 JADX 只做三方对照；四条路径均实际运行。
