## ADDED Requirements

### Requirement: 构造对象与谓词分支的二层双出口循环恢复

对于 Java 8 的受证二层条件分支，若内层一臂为空值赋值，另一臂含双出口无限循环，其中一个出口完整构造并保存对象、另一个出口在循环体中保存数组元素后经有序虚调用谓词决定，系统 SHALL 在两出口和空臂的局部值、内外汇合、每次调用与物理来源均闭合时输出可重编的结构化源码。构造、谓词和后继调用 MUST 只在原物理路径按原次数执行；任何必要证据不闭合时 MUST 保留整个相关区域的可定位物理引用。

#### Scenario: 固定 TestNotIndexedLoop 完整类
- **WHEN** 输入为固定 JADX `TestNotIndexedLoop` 对应的 `NotIndexedLoop` Java 8 class，分别以 null、空数组、含 `f` 数组及含 `h` 数组运行完整重编类
- **THEN** Jarde 完整源码 SHALL 在 Java 8 下重编并经 `java -Xverify:all` 输出与原 class、固定 JADX 相同的 `null / null / f / h`；目标方法没有 `@bytecode`，含唯一 `while (true)` 而不伪造索引 `for`，全部已消费物理 BCI 的来源和结构所有权可追溯

#### Scenario: 构造身份或效果顺序不闭合
- **WHEN** 分配、复制、构造与保存不是同一受证对象，构造参数增加未证明的效果，或构造值在保存之外另被消费
- **THEN** 系统 MUST 拒绝该循环折叠，不得丢弃或重复构造效果，也不得把未初始化对象呈现为源码值

#### Scenario: 谓词调用链或出口边界不闭合
- **WHEN** 数组元素、局部保存、接收者、`getName`/`equals` 调用结果与分支之间出现额外消费者、效果或不同目标，或循环增添入口、出口及异常边
- **THEN** 系统 MUST 拒绝该循环折叠，保持原求值顺序、可定位来源与安全引用

#### Scenario: 两层值汇合缺少唯一链路
- **WHEN** 内层三来源值经中间块转送到外层汇合，但转送、外层空值输入、判空或返回读取不能证明为同一值链，或任一汇合出现额外入边
- **THEN** 系统 MUST 拒绝相关二层结构，不得扩大局部词法范围或推测缺失值

#### Scenario: 已验收切片及停止状态
- **WHEN** 输入为既有双出口循环、二层空臂三来源汇合或其负例，或证明在预算耗尽、取消时停止
- **THEN** 既有可编译结果及拒绝边界 SHALL 保持；停止 MUST 不发布半份循环、局部值或来源图
