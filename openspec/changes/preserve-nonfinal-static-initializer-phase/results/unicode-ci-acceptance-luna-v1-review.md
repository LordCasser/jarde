# Unicode CI replay verifier review

`verify-unicode-ci-luna-v1.py` is an offline evidence verifier for the already captured `unicode-ci-root-v2` replay. It reads the evidence and writes `unicode-ci-acceptance-luna-v1.json`; it does not launch the frozen CLI, a JDK tool, Cargo, or CI. I checked its Python syntax with `ast.parse`; I did not execute the verifier.

The verifier closes the root wrapper’s actual invocation, exit status, and raw stdout/stderr hashes against the preparation script; validates the collector’s closed file inventory and every recorded command stream; checks the fixed CLI, metadata, source/test/canonical pins, fixture bytes, and JDK tool hashes; and binds command executable paths and arguments to the two JDK legs. It then checks two original compile/run legs, eight default/all JSON render legs, and four complete outer-source compile/run legs. For the archive input it requires the exact two stored class entries and their bytes to equal the original javac outputs. The complete generated family must compile from the outer `UT.java` alone with empty classpath/sourcepath and `-Xverify:all`, then match the original runtime bytes.

For both physical classes, it checks the full method and field identities against javap output. For all eight reports it checks method owner and identity, structured Java recovery, no fallback, and every present source-map origin’s BCI against that method’s original javap instruction list. The two outer static fields must retain the non-final physical fields and ordered `putstatic` proof BCIs from the original `<clinit>`; the generated text must contain the two Unicode declarations and the existing identity references.

Root reports that the collector completed with 30 commands, 14 cases, and all cases successful, with six byte-identical original/recovered runtime legs. These are observations from the captured root execution, not results of this verifier. The verifier and this review are prepared but unexecuted. No local Rust/Cargo test result is claimed; root deferred Cargo while the disk remained below the 20 GiB threshold.
