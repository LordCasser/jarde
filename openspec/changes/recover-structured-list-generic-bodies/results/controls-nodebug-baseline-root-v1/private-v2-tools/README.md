# CF11 debug-metadata control tooling

This private prep contains the existing CF11 collector plus the v6 exception-table observation checker. The collector adds `--source-debug {debug,none}`; it defaults to `debug`, preserving the current compiler behavior. The selected mode applies to every `javac` compile and is recorded both as `compiler_debug_info` in `execution.json` and as `collector_config.source_debug`. The only accepted compiler arguments are exactly `-g` for `debug` and `-g:none` for `none`.

For the no-debug baseline, add `--source-debug none` to the existing collector invocation. For the default baseline, omit the option or pass `--source-debug debug`. The checker validates the receipt/config match and reconstructs every expected compile command with that exact single flag. This v2 checker changes only its finite javap attribute-header recognition: it now stops after an exception table at `StackMapTable: number_of_entries = N`, where `N` must be decimal digits. It retains the v6 pinned-handler exception-table checks and all prior input/tool/raw-stream/source-map/profile/compile/runtime checks. The v1 checker failure invocation and raw streams remain untouched.

The collector's source/tool pins still include the collector itself and all original tracked inputs. The full collector/checker was not executed while preparing this directory. Pure-Python checks parsed the saved Java 8 and Java 23 no-debug classfiles and javap output, confirming that every physical exception table matches both the pinned parser count and javap, and the two JDK tables are identical. Run the checker independently against the already captured v1 no-debug receipt after review. This is observation tooling only and makes no product or behavioral acceptance claim.
