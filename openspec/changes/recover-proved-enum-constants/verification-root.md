# Root 独立验收：两常量枚举及用户静态后缀

本次类级投影已闭合 OpenSpec 指定的首片：`Stage` 输出两个带源级整数参数的 enum 常量；`Measure` 在常量之后保留 `static { totalUnits = sumUnits(); }`。Root 从最终源码重建 `jarde-cli`，SHA-256 为 `2a3664efd81b31cbbfe13837b4250f339ba43fd3754083da36cd4e7a380a9bca`。从冻结的原 Java 文件分别以 `javac --release 8 -g` 和 `-g:none` 重建 class，原/Jarde 完整类均重编并通过 `java -Xverify:all`：`StageRunner` 四次输出 `enum declaration checks: PASS`，`MeasureRunner` 四次输出 `user static boundary: PASS`；代理另确认两种模式的原/JADX/Jarde `Measure` 均为该输出。Root 独立编译 Counted 的原/JADX 两种模式，也与代理的 Jarde 结果同为 `calls=1,total=7`，证明用户 `sumUnits()` 的副作用未丢失或重复。

Root 审阅类级证明与源码装配：原 `$VALUES` 写入后的 Code 后缀必须恰为 BCI 34 本类 `sumUnits()I`、BCI 37 本类 `totalUnits:I` 写入、BCI 40 正常返回；同轮 AST 侧车必须为三项已证前缀 FieldWrite、唯一用户 FieldWrite、Return，字段身份、顺序及 RHS 来源逐项匹配。静态 `putstatic` 的 AST 可以带无运行时求值的本类类型限定 receiver；Code 的精确指令链排除额外接收者求值。RHS 用原表达式发射器计费，完整常量、构造器和静态块文本计费成功后才提交。预算或取消停止保持原字段式常量与完整 `<clinit>`，不发布半组源码。
