## Context

[矩阵证据](../../evidence/java-syntax-2026-10-01/inner-enum-args-patrol/nested-bodies-matrix/README.md)：顶层两格折叠、嵌套两格逐字段。旧切片义务证明（子类报告准备、ctor 委托体逐指令、纯覆盖成员集、structured 体方法、整组原子性）在顶层 fixture 上 root 验收；嵌套失败点大概率在名派生（如 `parent_of(child)` 按 `rfind('$')` 切段、或常量名 = 字段名与子类尾段比对）。

## Goals / Non-Goals

**Goals:** 嵌套名枚举常量体折叠 = 顶层同语义；矩阵四格结果翻转正确（两嵌套格折叠、两顶格局字不变）。**Non-Goals:** 义务证明放宽；混合形态（常量体+构造实参）；多级嵌套（`A$B$C` 枚举）首片只验一层嵌套，更深按需登记；接口 default 方法。

## Decisions

1. **先定位后修**：以 `Holder2$OpAbs` 单步调试/插桩定位首个拒绝点（子类选择、名匹配或常量投影），修复限于名派生语义（父名 = 子名去最后一段 `$N` 时须对嵌套父名逐段正确，或改用 InnerClasses 关系事实而非字符串切分）。**优先用 InnerClasses/ClassFile 结构事实而非字符串猜测**——若现实现是字符串切分，本次改为结构事实是正确所有者归属。
2. **回归锚**：矩阵四格 diff 断言（两折叠、两不变）；旧切片 `Op`/`Mixed`/`Plain` 既有测试全绿。
3. **验收**：两嵌套 jar 三方重编运行一致（`7`/`7` 与 apply 结果）；常量体方法文本含 @Override 判定沿用既有通道。

## Risks / Trade-offs

- **字符串修复引入新错位**（如 `A$B` 顶层用户类名）→ 决策 1 的结构事实优先；用户 `$` 类名负例（人为 `$` 命名的顶层类）钉死。
- **更深嵌套连锁** → 首片一层；`A$B$C` 形态如实登记不做。
