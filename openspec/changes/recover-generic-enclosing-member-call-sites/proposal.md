## Why

现有成员构造恢复在外层类带 `Signature` 时整体拒绝，调用方对嵌套类型的声明也保留二进制 `$` 名称。冻结的 Java 8 矩阵中，Jarde 因而不能恢复 `Outer.A<T>` 的普通与泛型成员创建；JADX 1.5.6 对四种调用都丢掉限定实例，输出的调用方均不能独立重编。已有目标类关系、构造器前缀和调用点 SSA/异常顺序证明可以作为扩展边界。

## What Changes

- 在选定环境中证明泛型外层类与其公开非静态成员的双向关系、外层类签名的擦除，以及调用点接收者的静态类型；允许证明成立的成员构造继续进入现有 `new@1` 判定。
- 把调用方签名中已证明的嵌套类型路径与每段类型实参写成 Java 源级名称；对成员泛型构造沿用已证明的物理首参与源级参数尾部对齐。
- 对原始目标 jar 独立重编并执行普通成员、泛型成员、`Object` 返回与参数化返回四种调用，验证非空/null 与实参效果顺序；证据不足时保持拒绝。
- 将 `Outer/A/Generic` 完整类族的声明树、词法类型变量作用域和构造器声明投影作为独立后续任务，不把调用方成功当成整 jar 成功。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `java8-recovery`: 扩展已证成员构造与嵌套泛型调用方的 Java 8 源码恢复边界。

## Impact

主要涉及 `src/member_inner.rs` 的选定外层证明、`src/facade.rs` 的依赖交接、`src/class_source.rs` 的调用方签名与类型拼写，以及 `crates/jarde-java` 现有 `New` 发射。Reader 的结构化签名解析和擦除证明应复用；不引入 JADX 运行依赖、CLI 专用核心逻辑或新的通用语法 pass。源码层的目标是调用方对原始目标 class 的独立重编；完整类族输出仍为单列债务。
