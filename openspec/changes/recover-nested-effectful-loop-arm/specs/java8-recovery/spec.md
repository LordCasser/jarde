## ADDED Requirements

### Requirement: 受证外层分支中的带效果双出口循环

当一个外层条件分支的一臂含有完整的带效果双出口无限循环，两个出口只在该臂内的同一后继汇合、执行一次直线尾段，再与另一臂汇合时，恢复器 SHALL 保留原 class 的执行路径、调用次数、局部值与每条物理指令的来源。若入口、出口、异常边、局部值或区域所有权不能完整证明，恢复器 MUST 保留明确的引用输出而不发布部分结构化循环。

#### Scenario: 外层空值分支与内层双出口循环

- **WHEN** 输入是冻结的 `NestedEffectful.pick(int[])`，外层空值臂返回 `-1`，非空臂的循环在越界时执行一次 `cost(7)`，在命中时直接退出，并只在循环后执行一次 `result + calls`
- **THEN** 原始、固定 JADX 和 Jarde 的完整 Java 8 类源码均可重编，`java -Xverify:all` 对空引用、空数组、命中、未命中依次输出 `-1:0`、`8:1`、`3:0`、`8:1`，Jarde 方法无 `@bytecode`，且循环、两个出口、内外汇合的物理来源均可查询

#### Scenario: 未证明的嵌套入口或汇合

- **WHEN** 同形输入加入额外循环入口、让两出口到不同后继、绕过循环后尾段、给内部汇合增加第三条入边或加入异常边
- **THEN** 恢复器 MUST 拒绝该循环的结构化投影并保留对应物理位置的来源，不得输出会改变执行次数的源码

#### Scenario: 预算或取消中止

- **WHEN** 证明或发布嵌套循环期间预算耗尽或请求被取消
- **THEN** 恢复器 MUST 原子停止，不得发布半个外层分支、半个循环或失去物理来源的尾段
