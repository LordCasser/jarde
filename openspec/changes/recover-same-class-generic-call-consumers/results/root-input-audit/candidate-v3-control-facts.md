This is an evidence extraction for the fixed candidate-v3 CLI across Corretto 8 / OpenJDK 23 and debug / no-debug (44 records). The replay script’s `CONTROL_REVIEW_ONLY` entries are preserved as root-review items; the earlier disposition explicitly applies to fixed CLI v1 and is context only.
