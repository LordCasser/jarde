## Context

[巡查证据](../../evidence/java-syntax-2026-10-02/nested-ctor-argument-patrol/README.md)：X2.nested 字节码 = 外层 `new@0; dup@3; ldc@4; [内嵌 new@6; dup@9; ldc@10; invokespecial@12]; invokespecial@15; invokestatic fmt@18`。走查（init.rs 约 429 行接收者检查处）按"自己的实参后紧邻自身 ctor"扫描，内嵌区间令 @12 被当外层调用点。第一个取证义务：读 `init.rs` 站点证明序列的扫描结构（实参收集如何推进 BCI、接收者检查触发点），确定内嵌站点的识别位与递归挂点。

## Goals / Non-Goals

**Goals:** 外层构造的任一实参位可为完整内嵌构造站点（同块、单用途、ctor 描述符匹配内嵌分配）；X2.nested/X1.main 恢复、行为一致；既有构造呈现逐字不变。**Non-Goals:** 三层以上深嵌套（首片验两层，更深按需登记）；内嵌站点跨块/双用途/栈残留（拒绝）；内嵌构造喂**方法**实参（已恢复，不碰）；数组初始化器内嵌构造；`this(...)`/`super(...)` 委托链内嵌。

## Decisions

1. **走查层识别 + 递归证明**：外层实参扫描遇 `new`+`dup` 起始的内嵌序列时，按同一站点判据递归证明（内嵌 ctor 与内嵌 allocation 匹配、单用途、区间封闭），成功则记录该实参为构造表达式并跳过区间；失败则外层按现行为拒绝（保守整组）。
2. **呈现复用**：内嵌站点经既有构造表达式拼写呈现于外层实参位（`new Y("inner")`），无新呈现函数。
3. **验收锚定**：X2（`outer`）+ X1（`inner`）+ 变体（双内嵌实参 `new X(new Y(), new Z())`、内嵌于第二参位、三层登记现状）；负例（内嵌双用途、内嵌缺 ctor）保持拒绝。

## Risks / Trade-offs

- **区间误跳（内嵌与外层交织）** → 判据要求内嵌区间完整连续且值单用途；"内嵌值又被外层外读"负例拒绝。
- **递归无界** → 深度上限 2（首片），更深保持拒绝并登记。
