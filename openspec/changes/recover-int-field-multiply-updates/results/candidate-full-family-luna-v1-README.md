# Candidate full-family replay (prepared only)

`prepare-candidate-full-family-luna-v1.py` is a prepared collector, not a run result. It reuses two closed, SHA-pinned input families: the EM23 `InputFieldIncrement2` `baseline-root-v2` and the multiply controls `baseline-root-v1`. Both old records have expected Jarde candidate failures, so the collector imports their successful original/JADX legs as raw/class/source oracles and does not count those old Jarde results as candidate success.

At execution, pass the exact frozen Jarde CLI and matching metadata with both SHA-256 values. The script checks the manifest and inventory hashes of both baselines, re-hashes every listed file, validates the two original plus four JADX cases in each family, checks their exact three-class sets and archived source/Runner artifacts, and binds original/JADX runtime bytes to the existing raw streams. It does not rerun original compilation or JADX.

The fresh candidate matrix is 8 Jarde renders (two families × two JDKs × default/all) and 8 full-source compile/`-Xverify:all` runtime legs. Each render uses the frozen original outer/`$A` class family jar. It preserves the full class-source text and JSON, verifies the outer and nested member census against the original `javap` output, compares physical member items with the old frozen report, and checks every source-map segment plus the union of primary and derived BCIs for every physical method. Fresh compiled outer and nested classes also receive a `javap` member census comparison so the replay proves that fields and methods were not dropped or added. `test1` is required to remain the explicit two-read `=` assignment; `test2` is required to show `*=`. Runtime exit/stdout/stderr must match the corresponding same-JDK original case, including the controls' overflow, null receiver, divide-by-zero, and old-field-retention observations.

Each generated product source is written and compiled unchanged. The only allowed source adaptation is package adjustment to the fixed Runner. Compile class census must be exactly the outer class, nested `A`, and Runner. Presentation checks are explicit for the two field-update forms; no old baseline failure is silently treated as a pass. The output is `results/candidate-root-luna-v1/` and refuses to overwrite an existing directory. This script has not been executed.
