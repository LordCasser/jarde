## ADDED Requirements

### Requirement: 不同汇合点之间的条件值组合

当一个 Java 条件值先在内层分支汇合，经过可完整证明的直线值运算，再作为外层分支的一臂进入另一个汇合点时，系统 SHALL 恢复完整的 Java 条件表达式或等价控制流。输出 MUST 保持每个测试、被选中的调用、运算和最终消费的原有求值顺序与次数；所有可达的汇合后指令 MUST 有唯一的源码归属。只有整个控制流和值依赖均已证明时才能呈现，任何局部成功不得留下空臂、未定义值或缺失返回。

#### Scenario: 内层值经运算进入外层返回

- **WHEN** 外层真臂的内层两臂先汇合为一个整数，再加常量并与外层假臂的整数汇合，最后返回
- **THEN** 完整类 SHALL 可用 Java 8 重编，三个正常输入各只执行所选调用，返回值和可观察效果顺序与原 class 一致

#### Scenario: 被选调用抛出异常

- **WHEN** 内层任一被选调用或外层假臂调用在产生值前抛出不同异常
- **THEN** 恢复后的完整类 SHALL 只保留该路径已经发生的效果并传播相同的异常；未被选调用不得执行，后续加法与返回不得发生

#### Scenario: 内层汇合后的物理来源

- **WHEN** 两个条件分支的汇合点不同且内层汇合后仍有可达指令
- **THEN** 默认与完整证据模式的 Java 正文 SHALL 一致，映射 SHALL 覆盖内层汇合、桥接运算、外层汇合和分支转移的实际物理指令，各指令只能由一个呈现位置或保守引用归属

#### Scenario: 组合证明不完整

- **WHEN** 中间结果有额外消费者、桥接段含独立效果或未知指令、存在异常或子程序边、外部入口或重叠归属，或者预算/取消在证明或呈现时停止处理
- **THEN** 系统 MUST NOT 发布部分折叠的条件表达式；保守结果 SHALL 保留整个候选范围的物理来源、拒绝原因或既有停止状态

#### Scenario: 相邻条件形状不退化

- **WHEN** 普通两臂条件值、所有叶子共用一个汇合点的嵌套条件值或无法证明的循环、switch、异常处理形状被处理
- **THEN** 已支持形状 SHALL 保持原有可执行行为和来源，无法证明的形状 SHALL 保持保守引用，不得被误识别为跨汇合点条件值
