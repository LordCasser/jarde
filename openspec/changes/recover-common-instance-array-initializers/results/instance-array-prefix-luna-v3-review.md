# Common instance-array initializer patch review (v3)

Patch: `instance-array-prefix-luna-v3.patch`. This is a private review artifact; it has not been applied to product sources.

The adapter keeps the existing opaque same-run constructor AST and `InitRecord`. It retains a constructor field-write sidecar only with the full AST, charges field evidence before cloning, and exposes only constructor-prefix identities, an AST-backed bounded equality operation, calls needed for helper validation, and the existing RHS emitter. Array checks and comparison use iterative walks; `NewArray` initializer nodes require the builder's actual `initializers: Some(..)` path with no lengths and rank one. `super(args)` remains the first statement; only the proved field-write prefix is removed, leaving the original suffix and `return`.

The facade requires a complete ordinary-class physical member/field census, then joins every constructor independently (non-constructor physical methods remain in the census). It admits one or more constructors, requires each to take a direct `super` prefix with identical ordered field identities and strongly equal AST RHSs, and validates same-class static helper declarations and signatures. Existing static initializer field order is used when available; otherwise field-vector order is the class-file source order. Any non-static `ConstantValue`, field declaration conflict, field-order inversion, `this()` path, handler, missing/unclaimed/duplicate store, differing RHS, or earlier member projection refuses the group. All fields, constructor member texts, and output charges are staged before a single commit; `RecoveryReport` text/maps are not rewritten.

Tests in the patch include an actual facade fixture with two direct constructors and `mark`, one-constructor literal fixture, differing RHS, `this()` delegation, reversed field order, a synthetic unrelated non-static `ConstantValue`, public analysis-budget/cancellation requests, plus AST-focused checks for `super(args)`/return preservation, unclaimed and duplicate writes, exact call arguments/overloads, primitive raw bits, and a budget stop.

Preparation only: the patch has not been applied or compiled. No Git, Cargo, rustfmt, JDK, JADX, or Jarde CLI command was run. The report-layer and facade tests still need root review and CI execution before the change can be accepted.
