# Byte-array return baseline collector review

`prepare-baseline-luna-v1.py` is prepared but unexecuted. It consumes only the already reviewed `inputs-prepared-luna-v1/ByteArrayReturn.java` and `Runner.java`, writes to a fresh `baseline-root-v1`, and refuses to overwrite that output. Run it with the pinned Python BLAKE3 dependency, for example `uv run --with blake3==1.0.11 python3 .../prepare-baseline-luna-v1.py`; the dependency is used only to record and bind the original class bytes to Jarde's class-source evidence.

The collector pins the existing JDK 8/23 manifest, JADX 1.5.6 launcher, and frozen instance CLI `5abb4bc82a50a8d427eff425ad80bc2fb845253b4216a81b60229e2337711663`. It compares two original full-source runs, four full-source JADX runs (default/none on each JDK), and four Jarde full-source runs (each original class rendered with both default/all evidence; the rendered body must be identical). JADX receives a deterministic jar containing only `javac23`'s `ByteArrayReturn.class`; the Runner is only added to compilation and receives a package prefix only when the generated class requires one. Every reconstructed target source is compiled as written with an isolated empty classpath/sourcepath and each runtime uses fresh output classes with `-Xverify:all`.

Commands retain argv, timestamps, exit codes, and byte-count/SHA-256 records for raw stdout/stderr. Original `javap -p -c -s -v` is retained for each JDK. Jarde JSON validation binds class and method owners to BLAKE3 of that exact original class, checks mapped source-map BCIs against the matching physical javap method, and records the physical field/method counts and the number of `new byte[]{...}` occurrences in the generated class text. Failures stay in raw outputs and case rows; the script never edits reconstructed target sources. This is a Java 8 source/classfile comparison plan and makes no ECJ or DEX profile claim.

No compiler, JADX/Jarde CLI, runtime, or collector was run during preparation. Python AST parsing is the only executable check performed after writing the collector.
