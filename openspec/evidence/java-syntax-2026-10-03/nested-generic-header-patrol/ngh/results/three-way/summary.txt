# 三方对照（Z1 与 NG 变体；主线 a7762a92 + 本片）

腿 A = 原 class（家族 jar 运行）；腿 B = 固定 JADX（dev）反编译→`--release 8` 重编→`-Xverify:all` 运行；
腿 C = Jarde 恢复文本重编（子单元按"install the patched original"惯例替换于家族 jar 之前运行原 main；
NG5 为折叠根整编运行）。运行输出 SHA 见 [sha256.txt](sha256.txt)，逐腿输出与 javac 日志在本目录。
