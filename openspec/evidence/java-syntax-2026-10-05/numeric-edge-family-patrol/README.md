# 数值边界族巡查（2026-10-05 root，负结果）

## 探针

[fixture/NU.java](fixture/NU.java)（`--release 8`）：`MIN_VALUE/-1` 回绕、`abs(MIN_VALUE)` 仍负、`>>>` 无符号移位、byte 位与提升链、移位+掩码、负数模、long 双向移位组合、`Integer.reverse`。

## 结果：**健康，无缺口**（quotes=0 / notrec=0）

- `MIN_VALUE / -1` 呈现为常量 `-2147483648`——**javap 核实（root 补验后更正初稿推断）**：`minNeg()` 字节码实为 `0: ldc #9 // int -2147483648; 1: ireturn`——javac 23 对该形（两编译期常量的除法）按 JLS 常量表达式**编译期已折叠**为 ldc 常量。即 jarde 的 `return -2147483648;` 是**对字节码的忠实呈现，非 jarde 求值**；初稿"jarde 做了求值"的机制推断错误（root 自查：写机制前未先 javap——与"最小门控实验"纪律同源）。真 javac 8 是否同样折叠未测（两编译期常量除法属 JLS 15.4 常量表达式，预期折叠，且本形无版本耦合窗口——产物只可能是 ldc 或 idiv 两形之一，jarde 两者都能呈现）；
- `abs`/`>>>`/`& 255` 提升/`<< 3 & 15`（运算符优先级呈现正确：`arg0 << 3 & 15` 在 Java 中 `<<` 先于 `&`，与字节码一致）/`%` 负模/long 双向移位/`reverse` 全部如实；
- 行为 8 值逐行 IDENTICAL（含两个回绕值与 `-1` 负模）。

## 处置

负结果归档，不立 spec。数值边界族确认覆盖；常量折叠呈现（纯运算求值）记为呈现特征数据点（等价、无副作用前提成立）。
