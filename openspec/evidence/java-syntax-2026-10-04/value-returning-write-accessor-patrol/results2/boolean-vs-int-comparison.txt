### 决定性对照：同类内 boolean vs int 写访问器（真 javac 8 / Corretto 1.8.0_432）

源形: class BA { private boolean flag; private int count; class S { void setB(boolean b){flag=b;} void setI(int i){count=i;} } }

[1] 两个写访问器的 opcode 序列**逐字相同**（javap 实录；root 以 awk 精确取单方法复核，两者均为下述 5 条、`diff` 为空）:
    access\$002 : aload_0 iload_1 dup_x1 putfield ireturn
    access\$102 : aload_0 iload_1 dup_x1 putfield ireturn 
    描述符: access$002=(LBA;Z)Z   access$102=(LBA;I)I   ← 仅字段/返回类型不同

[2] jarde 呈现（合并态二进制，源码区）:
    boolean access$002 → **恢复**: 'arg0.flag = arg1; return arg1;'
    int     access$102 → **拒绝**: 'not recovered'，引注 @bytecode 2/3/6（'the instruction at BCI 2 is not part of the provable subset'）→ 空 stub
    源码区 quotes=3, not-recovered=1

[3] 严重性（渲染源集重编）:
    javac --release 8 exit=1  错误: 缺少返回语句
    → 空 stub 带 int 返回类型 ⇒ 整类不可编译（响亮失败，非静默偏离）

[4] 判据定位（root 读码）: build.rs:8848-8851 的 BooleanAccessorAssignment::prove 要求
      field.owner == owner && field.descriptor == "Z" && field.access == Write && !field.is_static
    → descriptor != "Z" 即 return Ok(None)，故**只有 boolean 字段的写访问器被接受**
    该处理器由 d09f5dea（"recover proved parent field writes and private setter helper"）交付，调用点 build.rs:7293
