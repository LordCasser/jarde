# 已接受比较的操作数恢复失败

自写 `NumericRefusal.value` 比较一次外部float调用与`0.0f`。该浮点常量仍为未支持值，比较结果虽满足紧邻零分支准入，整个条件仍须明确拒绝。

原class与JADX完整类各6行执行一致，涵盖NaN、负值、正负零、正值及调用自身抛错，每次调用计数均为1。数值比较实现后的debug CLI保留引用BCI 0、1、4、5、6、9、12，其中1为延期调用、4为未支持常量、5为比较、6为零分支。调用没有因延期而从拒绝结果中丢失，未声称该不完整Java正文能够重编译。

`run_audit.py`可复放，source-only helper/runner及实际javap、两份反编译、执行输出均在本目录。输入class只生成在临时目录，无新增永久语料。
