# TestNestedLoops same-IR diagnostic candidate v1

This is a private, unapplied, uncompiled temporary diagnostic candidate. It is for the frozen `cf11.UpstreamNestedLoops.test(Ljava/util/List;Ljava/util/List;)V` class-source run only. It does not propose a product fix.

The paired candidate sources and `candidate.patch` are based on the pinned current `build.rs` and `facade.rs`. The facade test reads the exact JDK 23 class bytes pinned below and enters the existing public `Engine::class_source()` path using `SnapshotAll`, `SingleClass`, Java 8, MR disabled, Generic layout, and loader `app`. Recovery facts (including instance `parameter_slots=3`, declaration/access/class identity, descriptor-derived parameter types, and Code LVT/LVTT locals) therefore come from the production class-source path. The test does not construct `RecoveryFacts` manually.

The test is ignored by default. Run only this exact ignored test with `JARDE_FOREACH_CANDIDATE_DIAGNOSTIC=1` and the harness’s exact-test/ignored selection. The logger checks this environment variable at each event and writes compact `JARDE_FOREACH_CANDIDATE` records to stderr. The test itself asserts that the explicit opt-in is present. Events include `attempt` or `skipped` at the loop-builder eligibility branch, physical `test_bci`, `header_bci`, region path, loop form, number of tests, for-header state, and the built loop body's first statement variant. Candidate entry emits distinct first-gate labels for non-while kind, release profile, condition AST shape, exact `Iterator.hasNext` invoke shape, and first body statement not being an initialized declaration. A later proof closure returning `None` is reported only as `post_entry_candidate_proof_incomplete`; successful proof, later rewrite refusal, projection, and `StopReason` are distinct outcomes.

That grouped later refusal is intentional. The closure contains many short-circuit `Option` paths and `?` propagation; the preceding reverse `find_map` also uses `None` for local search misses. This candidate does not label those internal misses as the foreach candidate's first refusal and makes no specific interior-gate claim. It records the exact high-level boundary needed to tell first-gate rejection from a later proof failure. If root needs the interior first refusal, it can add a separately reviewed, gate-by-gate temporary trace while preserving `find_map` local semantics.

The instrumentation is local, opt-in stderr output; it adds no public API, global state, or persisted data model. Candidate refusal predicates retain their order. At the callsite, the former `?` propagation of `StopReason` is written as a `match` solely to emit a `stopped` event, then returns the same reason. No build/test/toolchain command was run for this candidate, so compile validity is unverified. Root must review/apply it only after the current product CI work is complete, and must restore the two shared files after any guarded run.
