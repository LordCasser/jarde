# Frozen fixture notes

Formal task 1.1 fixture corpus for `recover-same-class-generic-call-consumers`. Acceptance is GC-01 through GC-08, plus the carried baseline families. New source files are listed in `frozen-input-index.json`; each is compiled independently for the four legs. Existing CallHold, ExceptionHold and BoundOverload jars are indexed with their original per-leg paths and SHA-256 and must be copied/replayed byte-for-byte. Do not regenerate these three historical inputs.

The matrix has 32 new source classes and three reused frozen families (35 source families total). New fixtures cover direct/void/empty calls, result relays, arrays and dimensions, bounds, multiple class variables and wide slots, dependency depth and declaration order, method binder shadowing/substitution, same-erasure independent binders, same-class typed/raw/rebound receivers, constructor normal and throwing paths, overload controls, and conservative cycle/bootstrap/multi-use/varargs/bridge/inheritance controls.

`VoidDirect` is retained as a known successful control. The prior external-List raw/mutation exploratory cases in `/tmp/jarde-generic-call-patrol-v1/v3` are historical refusal evidence only; they are not same-class positive fixtures.

Every positive/negative control uses its complete target source and jar. `BridgeUnknown.java` intentionally contains the package-private `BridgeBase<T>` helper so the jar includes both generated class files; whole-source comparisons must include/decompile both classes. `InheritedUnknown` relies only on the JDK runtime classes. The legal incompatible same-erasure fixture uses `T extends Number` and `<U extends Number & Runnable>` and calls `sink(null)`, so the original source compiles while binder identities/bounds remain distinct. `UnknownIncoming` retains an explicit legal unchecked cast from `Object` to `T` and an independent leaf.

The probe must walk `ParameterizedType`, `GenericArrayType`, and `TypeVariable`; compare `getGenericDeclaration()` with the exact declaring class/method/constructor and formal index; and check bound identities. Marker results include direct object identity, array identity, Number value 17, multiargument position, wide-slot position, constructor normal/throw branches, and overload target selection. Probe Java source and its own hash must be stored.

The four legs are Corretto 8u432 and OpenJDK 23.0.1, each with `-g` and `-g:none` (OpenJDK 23 compiles with `--release 8`). All recompiled sources use an explicitly empty classpath and sourcepath; each runtime uses only its new classes and `-Xverify:all`. Jarde CLI success is recorded separately from whole-class javac, behavior and structured reflection. Failed harness runs stay preserved and new attempts use new output directories.
