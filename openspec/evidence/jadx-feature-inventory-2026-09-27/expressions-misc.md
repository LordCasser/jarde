## 非语法审阅结果与剩余项

- `debuginfo` 的 5 个文件测行号、局部变量名或来源映射；`deobf` 的 8 个与 `rename` 的 7 个文件主要测别名策略/用户重命名/继承链接。它们影响输出名字的有效性，但不是新增 Java 语法。入口分别是 `dex/visitors/debuginfo/DebugInfoAttachVisitor.java`、`DebugInfoApplyVisitor.java`，以及 `dex/visitors/rename/RenameVisitor.java`、`CodeRenameVisitor.java`、`UserRenames.java`、`SourceFileRename.java`。
- `variables/TestVariablesDeclAnnotation.java` 名称中的 annotation 是代码元数据 `NodeDeclareRef`，测试参数声明位置的映射，不是 Java 注解语法；它为 EM-20 提供来源约束。`rename/TestRenameEnum.java` 虽以重命名为主，确实含枚举常量类体的源级形状，故另列 EM-30。
- `android` 的 7 个文件恢复 `R.id`/`R.attr` 和资源常量：`android/TestRFieldRestore.java`、`android/TestResConstReplace.java` 为代表。`codegen/InsnGen.java` 的静态字段访问处理会接入 Android 资源类；这是平台资源映射，不应列为 Java 新语法。
- `fallback` 的 2 个文件检查标签、指令转储及过量 NOP；`jbc` 的 2 个文件检查 JVM `dup`/栈转换到普通赋值或调用。`others/TestAllNops.java`、`others/TestMultipleNOPs.java`、`others/TestWrongCode.java`、`others/TestWrongCode2.java` 属同类稳健性边界，不能用其退化文本宣称可编译源级恢复。
- `others/TestCodeMetadata.java`、`TestCodeMetadata2.java`、`TestCodeMetadata3.java` 与 `TestJsonOutput.java` 测映射/序列化；`TestUsageApacheHttpClient.java` 测使用关系；`TestClassReGen.java` 测重新生成流程。注释类测试列在 EM-28 作为文本边界，不归入表达式语义。
- 逐目录 **224/224** 个文件均落入以上源级特性、拒绝/容错边界或非语法审阅组；未分类残项 **0**。特性表按语义交叉引用，未把每个文件虚构成一个独立语法特性。后续实现须重新检查每个负例的断言级别，尤其 `@NotYetImplemented` 与 `disableCompilation()`，再据物理证据决定能否投影。
