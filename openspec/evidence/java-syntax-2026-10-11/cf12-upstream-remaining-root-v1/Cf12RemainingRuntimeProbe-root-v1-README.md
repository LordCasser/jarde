# CF12 remaining-fixture runtime probe draft

`Cf12RemainingRuntimeProbe-root-v1.java` is a private, uncompiled source draft for use after the direct harness has captured the five target class files. It accepts the exact captured target binary name plus one of the fixture names and uses reflection against that target. It has no compile-time dependency on the test classes, does not rewrite class bytes, and does not invoke a CLI or toolchain.

The three source fixtures with a public `check()` (`TestSwitch3`, `TestSwitch4`, and `TestSwitchWithFallThroughCase2`) run that original oracle first. The probe then adds narrowly chosen method calls: Switch3 states for returns/default and negative/extreme selectors; Switch4 valid numeric character slices including the two source check examples; and the conditional fall-through fixture's `a=-5..9` plus both int endpoints crossed with all `b/c` booleans. TestSwitchSimple has no upstream `check()`, so it runs its public `test(int)` on representative negative remainders, zero, the case labels/default, and integer endpoints while retaining the method's stdout between stable markers.

`TestSwitch2` has no source `check()` either. It has five booleans and one float field (six state fields total). The draft enumerates all 32 initial boolean configurations, varies a nine-value float seed set (including `+0`, `-0`, threshold-adjacent finite values, both infinities, and NaN), and exercises each configured state with actions `0,1,2,5,6,261,-1,-256,-255,-254,-251,-250`. Separate one-call instances isolate each action. A short mutation sequence then checks interactions after case 5 (`261` is a case-5 selector with an original value greater than 10), case 2, cases 6/1, and ordinary/default actions. Each step emits all five boolean values and the float text plus raw IEEE-754 bits. This is a balanced coverage matrix, not every boolean × float × action Cartesian product; it avoids flooding output while preserving all 32 boolean states and every selected edge value/action class.

This probe is only an execution observer. It cannot replace the JUnit source assertions, full source recompile, exact original/JADX/Jarde compilation and stdout/stderr comparison, or source/class coverage inventory. The three existing `check()` methods supply upstream assertions; Switch2 and SwitchSimple still have no original runtime assertion, so their probe cases provide explicit differential inputs rather than a new upstream expected-value oracle. Check methods that reference AssertJ require the same pinned official test SDK on the runtime classpath. The full-replay helper classpath must continue to exclude the captured `jadx/tests/integration/switches/Test*` target classes so they cannot mask a candidate output class.

No compiler, formatter, Cargo, JDK, CLI, or Git command was run. The file was not written to the workspace.
